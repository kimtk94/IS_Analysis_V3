The full script also enumerates ties and unequal panel counts; ties are excluded from sign-test n, not classified as negative. Scenarios are not observed results or equally probable events. The nested panels and nonrandom missingness preclude inference of independent clinical response or a responder/nonresponder difference. No changing the fixed panels, adding donors retrospectively, or selecting significance-based analysis.

NCBI BioProject https://www.ncbi.nlm.nih.gov/bioproject/729873 lists 16 SRA experiments, ~127 Gbases, ~52,984 MB. The original paper https://pmc.ncbi.nlm.nih.gov/articles/PMC9140469/ declares raw SRA data and describes supplementary top-gene tables, not a complete per-run count matrix. A second paper uses the same 7-day accession, https://pmc.ncbi.nlm.nih.gov/articles/PMC9117214/. Treat these as one dataset. Recount3 is not currently updated (https://registry.opendata.aws/recount/); study coverage is not verified. Next: use exact ENA run/MD5 and approved resource budget, confirm all 16 in one uniform count release or quantify all 16 using the same pipeline, reference and annotation. Do not mix only missing arms from a distinct pipeline. Resource-intensive raw processing is not launched here.
