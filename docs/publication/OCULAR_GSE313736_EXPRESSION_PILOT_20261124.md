# GSE313736 frozen panel expression pilot and inference decision

This protocol is fixed before expression download/scoring. Source GEO GSM9373278 pool-C (vehicle) and GSM9373287 pool-dexC (500 nM dex), same eight reported donor IDs, GRCh38.p13 Cell Ranger filtered GEX. Their published count matrix sizes 327.8 and 358.1 MB (displayed units). Pilot C chosen because both original GSM identities and matched donor membership already verified, not on expression. Use pinned 169,398 SNG metadata and original frozen panel archive (241, ECM16), exact library and sample membership, unique reversible barcode identity with optional terminal -1 normalization, stable Ensembl gene IDs, exact feature universe and integer count shape. Require every retained metadata barcode matched; exclude other matrix cells per original released metadata, not by observed response. Require >=90% mapped 241 and all 16 ECM. All released SNG cells as primary global TM-culture response (not validated single cell subtype); no gene-level or cell-specific discovery in pilot. Sum full GEX UMI counts per sample x arm; signed mean of log2(CPM+1) differences using fixed signs. Minimum cells per arm 100 primary, 50/200 sensitivity; descriptive one-pool summaries only, no P value or independent replication claim. Output no donor ID, genotype, clinical metadata, per-donor expression or raw reads.

Strengthen original proposed inference before data access: exposure assigned at pooled culture/library level, nine paired pools. Donor pairs share technical and treatment effects, so after complete matrix/QC review, use equal-donor mean panel response within each pool and two-sided exact sign test across nine pool pairs, Holm across two panels, as primary conservative inference. Donor-level sign counts and descriptive distribution secondary; do not treat 59 donors or 169,398 cells as independently randomized exposure units. Require all predefined pool pairs and report attrition. Verify no donor appears in >1 pool per condition and matched pools are same donor set, based on original sample record and metadata. Equal pool weight and leave-one-pool-out sensitivity. Source batch effects, finite pool number, study overlap, known glucocorticoid-response literature and lack of clinical IOP phenotype remain limitations. No genotype retrieval or analysis. Full raw matrices not committed. Pilot technical failure stays HOLD; do not silently relax identity checks or switch cohort based on signs. No full historic smoke test or main merge.
