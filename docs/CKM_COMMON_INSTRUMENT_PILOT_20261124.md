# CKM publication: common-instrument pilot

Follow-up to PR #333's published-estimator contrasts, kept on a separate main-based draft branch to avoid re-running that PR's unrelated heavy jobs. Radiomics and harness are out of scope.

**Source choice:** Willer et al. 2013 GLGC joint GWAS/Metabochip LDL-C public result, official schema/allele definition at https://csg.sph.umich.edu/willer/public/lipids2013/ (DOI 10.1038/ng.2797). This is an alternative historical exposure sensitivity, not the originally planned 2021 GLGC full panel. For SBP, inspect the publicly released Keaton et al. 2024 supplementary workbook (DOI 10.1038/s41588-024-01714-w); do not use score weights as exposure effects or bypass the separate Evangelou/OpenGWAS restrictions.

**Pilot selection fixed before reading outcomes:** autosomes; P<5e-8 and F>=29.7168; N>=50000; EUR reference AF .01-.99; nonpalindromic biallelic SNP; exclude chr6 25–34 Mb; select minimum reported P per chromosome, tie-break decreasing F then coordinate/rsID, reject selected coordinate duplicates with no replacement. P=0 only admitted if absolute z>=37 and treated as underflow. This sparse panel intentionally sacrifices power to avoid within-chromosome local LD, not proof of independence across chromosomes or the planned genome-wide clumping.

Use original EUR GRCh37 GIGASTROKE LAA=GCST90104542, CE=GCST90104541, SVD=GCST90104543; require published MD5, exact prior verified bytes and row counts, strict allele orientation and unique target coordinate. Take the three-outcome intersection, at least 10 SNPs, no outcome P selection, no proxies. Compute per-outcome first-order IVW and direct weighted regressions of per-SNP differences with worst-case covariance SE=SE1+SE2, multiplicative dispersion floor 1, and leave-one-out. Bonferroni family six (includes the three pending SBP comparisons). Interpret only as exploratory conditional on independent autosomal estimators, comparable effect units, and valid marginal errors; no SNP-level covariance estimated, no multivariable MR, no cohort independence, no scientific promotion. Missing inputs produce explicit HOLD JSON. No raw data in Git; only small derived public artifacts in Actions.

Run bounded public-source jobs in parallel. LDL outcomes download once per run after successful exposure selection, not a genome-wide LDSC job. SBP inspection does not download a full GWAS. Tests and smoke are run on GitHub-hosted runner because this connector-only change does not have a local worktree; report failures rather than claiming precommit test PASS. No server deployment, schedule or automatic merge.
